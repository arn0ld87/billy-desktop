## Agent skills

### Issue tracker

Issues und PRDs liegen als GitHub Issues in `arn0ld87/billy-desktop` (über die `gh` CLI). See `docs/agents/issue-tracker.md`.

Die fünf Standard-Rollen mit identischen Label-Namen (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: ein `CONTEXT.md` plus `docs/adr/` im Repo-Root. See `docs/agents/domain.md`.
